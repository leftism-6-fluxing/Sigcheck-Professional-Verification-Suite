## Frequently Asked Questions

### Is this tool an alternative to the original Sigcheck utility?

Yes. Sigcheck Professional Verification Suite builds upon the concept of signature verification and enhances it with a graphical interface, batch processing, detailed reporting, and modern Windows 10/11 compatibility — features not available in the original command-line utility.

### Will this software work on my antivirus-protected computer?

Most antivirus programs recognize this tool as a legitimate system utility. If your antivirus flags the installer, you can safely add it to your exclusion list. The application does not modify any system files and operates in a read-only mode by default.

### Can I scan specific file types other than EXE and DLL?

Absolutely. The tool supports a wide range of file types including EXE, DLL, SYS, OCX, and other PE format files. You can also verify files cataloged in Windows security catalogs (`.cat` files).

### What do the different signature statuses mean?

A **Valid** status indicates the file has a legitimate, trusted signature. **Unsigned** means the file contains no digital signature. **Invalid** or **Revoked** suggests the signature may have been tampered with or the certificate has been revoked by the issuing authority.

### Does this tool require an internet connection?

No. All signature verification is performed locally using your system's certificate store and the Microsoft catalog database. An internet connection is only needed for downloading updates to the certificate revocation list.
